# Aliving2D

애니풍 캐릭터 그림 한 장으로 캡슐(CAPSULE)에서 쓸 2.5D 캐릭터 모델을 만드는 개인용 로컬 도구입니다.
v2는 **Live2D 장인이 모델을 만드는 순서를 그대로 따라가고, 사람이 손으로 하던 단계를 AI와 규칙으로 바꾸는** 방식입니다.

```
그림 ─(GPT: 정면)─▶ 정면 그림 ─(see-through)─▶ 파츠 PSD ─(장인 규칙 리거 + GPT 그린 상태)─▶ 묶음 v2 ─(v2 엔진)─▶ 재생
```

- **고개 돌리기 X·Y**: 머리를 원통으로 보고 파츠마다 깊이를 정해 키폼을 만듭니다(코는 더 나오고, 뒷머리는 반대로 움직임).
- **시선**: 눈동자를 원으로 완성하고 흰자 안으로 잘라 움직입니다.
- **깜빡임**: 피부 눈꺼풀을 속눈썹에 붙여 같이 움직입니다. 속눈썹은 위·아래·쌍꺼풀 선으로 나눕니다.
- **웃는 눈**: 변형으로 가늘어지다가 끝에서 GPT가 그린 ^ ^로 바뀝니다(Live2D 描き目).
- **입**: GPT가 그린 벌린 입을 입 안·이·혀·입술 선으로 나눠 렌즈 모양으로 엽니다. 웃는 입·시무룩한 입.

v1(편집기, 공식 기반 엔진)은 git 태그 `v1-final`에 남아 있습니다.

## 시작하기

```bash
npm start      # http://127.0.0.1:8000/ → v2 뷰어
```

모델 만들기 (지금은 명령으로):

```bash
# 1) see-through로 정면 그림을 파츠 PSD로 (GPU PC)
# 2) 묶음 v2 만들기
python py/export_bundle.py <psd> bundles/<이름> --src <정면 그림> --mouth-open <입 벌린 그림> --smile-eyes <웃는 눈 그림>
```

뷰어: `http://127.0.0.1:8000/viewer/index.html?model=../bundles/<이름>/model.json`
