    순서
    
    
      
      
    1. PSD 열기 — 파츠로 나뉜 PSD를 놓습니다. 그림만 있으면 시작 화면의 Colab 안내대로 PSD를 만듭니다.
      2. 
      
    2. 점검 — 자동 리깅 결과를 보고, 눈·입·팔 관절이 어긋났으면 「기준점 맞추기」로 점을 옮깁니다.
      3. 
      
    3. 움직여 보기 — 표정, 머리, 팔을 움직이거나 카메라로 따라 해 보며 이상한 곳을 찾습니다. 여기 값은 저장되지 않습니다.
      4. 
      
    4. 모델 조정 — 눈을 감는 시점, 입 크기, 흔들림 세기처럼 캐릭터에 맞춘 값을 다듬습니다. 모델에 저장됩니다.
      5. 
      
    5. 캡슐 모델 내보내기 — ZIP을 받아 bundles/이름/에 풀면 캡슐 플레이어에서 재생됩니다.
      6. 
    
    
    
    단축키
    
    
    
    
    레이어 이름
    
    
    see-through가 만든 PSD는 그대로 됩니다. 직접 만든 PSD는 face, eyewhite, irides, eyelash, eyebrow, mouth_open, mouth_close, front hair, back hair, topwear, handwear 같은 이름(또는 일본어 「顔・白目・前髪」)을 쓰면 자동으로 인식합니다.
